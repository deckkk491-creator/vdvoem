# Переезд базы в Россию

Зачем: ч. 5 ст. 18 152-ФЗ (в ред. 23-ФЗ, с 01.07.2025) — запись, хранение и другие действия с персональными данными
граждан РФ выполняются только с базами данных в России. Сейчас проект Supabase `vdvoem` в Ирландии (AWS eu-west-1),
поэтому до переезда публичный запуск в РФ невозможен.

## Решение
Тот же Supabase (у него открытый код), но на своём сервере у российского провайдера. Код приложения почти не меняется:
другой адрес сервера и ключ (`EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_ANON_KEY` в EAS или новые значения
по умолчанию в `src/lib/env.ts`). Миграции 0001–0007, RLS, realtime, хранилище файлов, вход по коду и Edge Functions
(`link-preview`, `delete-account`, `yandex-signin`) работают так же.

## Что нужно от владельца
1. Сервер (VPS) у российского провайдера из реестра хостинг-провайдеров РКН: 2 vCPU, 4 ГБ памяти, 40+ ГБ диска,
   Ubuntu 24.04. Варианты: Timeweb Cloud, Selectel, Yandex Cloud, VK Cloud.
2. Домен для HTTPS, например `api.<домен>.ru` (сертификат Let's Encrypt выпускается только на домен, не на IP).
3. Доступ к панели провайдера и регистратора — дальше всё делает Claude через браузер.

## План (делает Claude)
1. Поставить Docker и официальный `supabase/docker` на сервер, задать свои секреты (JWT, ключи, пароль БД),
   закрыть всё, кроме 443, включить HTTPS (Caddy или Nginx + Let's Encrypt), резервные копии БД раз в сутки (хранить 30 дней).
2. Перенести базу: дамп схем `public`, `auth`, `storage` из облачного проекта → восстановление на сервере
   (пользователи и их входы сохраняются). Проверить миграции 0001–0007 и тесты RLS на новой базе.
3. Перенести файлы бакета `space-files` (тот же путь объектов).
4. Настроить почту (SMTP Яндекса — те же логин и пароль приложения), шаблоны писем, Site URL и Redirect URLs
   (`vdvoem://**`, без `exp://**`).
5. Развернуть Edge Functions и секрет `YANDEX_CLIENT_ID`.
6. Новый адрес — в EAS и `src/lib/env.ts`, собрать тестовый APK, проверить вход, пространства, фото, удаление аккаунта.
7. Обновить `docs/privacy-policy.html` (вписать провайдера), CLAUDE.md, README; облачный проект удалить
   после проверки (там остаются копии данных).

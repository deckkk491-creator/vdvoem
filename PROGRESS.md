# «Вместе» — где остановились (30.10.2026)

Приложение переименовано из «Вдвоём» в «Вместе». Работаем только над ним; HomeFit пока на паузе.

## Готово
- **Переименование.** «Вместе» на телефоне, на экране входа, в разрешениях iPhone, в текстах App Store (`store/`), на сайте и в политике (`docs/`). Технические имена прежние: репозиторий и схема `vdvoem`, Bundle ID `com.deckkk491.vdvoem`, проект Supabase `vdvoem`. В App Store название — «Вместе: планы для пары и семьи» (просто «Вместе» уже занято похожими).
- **Исправления по аудиту** (ветка `audit-fixes`, CI зелёный):
  - миграция `supabase/migrations/0004_security_hardening.sql` + тесты `supabase/tests/rls_v4_test.sql`: права в базе, коды приглашения 8 символов и лимит 10 попыток за 10 минут, исключение участника, смена кода, удаление аккаунта без потери общих записей партнёра, realtime об удалениях только для участников;
  - вход по ссылке из письма — только PKCE `code`, с подтверждением смены аккаунта;
  - link-preview и скрытый браузер не ходят в локальную сеть;
  - настройки: список участников, «Исключить», «Сменить код»; удаление аккаунта без «половинчатого» состояния;
  - голосовые без дублей, даты 2-2-2 без перескока месяца, безопасный тип загружаемых файлов, читаемые неактивные кнопки;
  - политика конфиденциальности обновлена (что остаётся у партнёра после удаления аккаунта).
- **Разбор перспектив:** https://claude.ai/artifact/PDKHfaUnDwC9zWJrBRpSPp — рынок, конкуренты, заработок (партнёрка Яндекс Маркета → подписка), план запуска ноябрь 2026 – апрель 2027, метрики, риски.

## Сделано 30.10.2026: версия для Android (ветка `android-support`)
- **Сборка.** `eas.json`: `preview` и `development` дают APK, `production` — AAB для Google Play, `production-apk` — APK для RuStore или раздачи, в `submit` добавлен Android. `app.json`: значок уведомлений, одноцветная иконка для тем Android 13+, переработанный передний слой иконки (внутри безопасной зоны), `allowBackup: false`, заблокированы разрешения на календарь. Календарь телефона на Android выключен намеренно (см. `src/lib/deviceCalendar.ts`).
- **CI.** Шаги `Bundle for Android` и `Android project and manifest (prebuild)`: собирает проект, печатает итоговый манифест и список разрешений, падает, если в него попал календарь или нет схемы `vdvoem`.
- **Документы.** `docs/delete-account.html` (обязательна для Google Play), обновлены `docs/privacy-policy.html`, `docs/support.html`, `docs/index.html`; `store/google-play.md` — публикация, анкеты, список проверок на телефоне; README и CLAUDE.md.

4. Проверить в Expo Go вдвоём на двух телефонах: участники, «Исключить», «Сменить код», вход по ссылке, чат при переключении пространств.
5. Перед релизом убрать `exp://**` из Redirect URLs в Supabase.
6. Оплатить Apple Developer аккаунт ($99/год).

## Запуск для теста (терминал на маке)
```bash
cd ~ && { [ -d vdvoem ] || git clone https://github.com/deckkk491-creator/vdvoem.git; } && cd vdvoem && git fetch origin && git checkout main && git pull && npm install && npx expo start -c
```
Если телефон не подключается: `npx expo start -c --tunnel`.

# «Вместе» в RuStore

Первый магазин — RuStore (решение владельца 27.11.2026). Публикация бесплатная, разработчик — физическое лицо.

## 1. Что делает владелец (за него нельзя)
1. **Кабинет разработчика:** console.rustore.ru → войти через VK ID или Сбер ID → «Физическое лицо» → подтвердить личность через Госуслуги. Если позже понадобятся платные функции — статус самозанятого.
2. **Expo-аккаунт** (бесплатно, expo.dev) — в нём EAS собирает подписанный APK и хранит ключ подписи.

## 2. Сборка (один раз нужен терминал на Маке)
```bash
cd ~/vdvoem && git checkout main && git pull && npm install
npx eas-cli@latest login
npx eas-cli@latest init
npx eas-cli@latest build -p android --profile production-apk
```
- `init` привяжет проект к Expo и допишет `extra.eas.projectId` в `app.json` — изменение нужно отправить в репозиторий (или прислать ID Claude).
- На вопрос «Generate a new Android Keystore?» ответить **Yes**.
- Сборка идёт в облаке ~15–20 минут, в конце — ссылка на `.apk`.
- **Сразу после первой сборки:** `npx eas-cli@latest credentials -p android` → скачать резервную копию ключа (keystore) и хранить вне репозитория. Без этого ключа обновить приложение в RuStore будет нельзя.
- Номер сборки (versionCode) EAS увеличивает сам (`autoIncrement`, `appVersionSource: remote`). Версия для людей — `version` в `app.json` (сейчас 1.0.0).

### Краткое описание (≤ 80 символов)
Общий календарь, кино, рецепты, покупки и бюджет для пары, семьи и друзей

### Полное описание
«Вместе» — общее пространство для пары, семьи или компании друзей. Календарь, фильмы на вечер, рецепты, идеи для выходных, список покупок, бюджет и вишлисты — в одном приложении, у всех участников сразу.

КАК НАЧАТЬ
• Войдите через Яндекс ID или по почте — придёт код, пароль не нужен.
• Создайте пространство и отправьте близким код приглашения — или присоединитесь по чужому коду.

РАЗДЕЛЫ
• Календарь — события, задачи и важные даты с напоминаниями. В день праздника — фейерверк на весь экран.
• Кино — фильмы и сериалы: хотим, смотрим, посмотрели.
• Еда — рецепты по ссылке и подсказка «Что приготовить сегодня?».
• Выходные — куда сходить и что попробовать; прошедшее уходит в отдельный список.
• Покупки — общий список, отмеченное исчезает само.
• Бюджет — расходы и доходы по категориям; можно заполнить по QR-коду чека.
• Рабочие дни — у кого какие смены, видно в общем календаре.
• Копилка и вишлисты — общие цели и списки желаний. Близкие могут тайно отметить «Подарю я».
• Правило 2-2-2 — свидание раз в 2 недели, новое место раз в 2 месяца, новая страна раз в 2 года, с идеями по сезону.

ЛАЙКИ
Добавили идею — остальные отмечают, что им тоже нравится. Так сразу видно, что выбрать.

ПОД СЕБЯ
Тёмная и светлая тема, чёрная тема для OLED-экранов, цвета и фоны, свой набор кнопок на нижней панели.

ДАННЫЕ И ПРИВАТНОСТЬ
• Без рекламы и трекинга, данные не продаются.
• Содержимое пространства видят только его участники.
• Аккаунт и данные можно удалить прямо в приложении.
